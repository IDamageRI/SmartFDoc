# Исправления и улучшения системы

## ✅ Исправленные критические ошибки

### 1. Ошибка `'sqlite3.Row' object has no attribute 'get'`
**Проблема:** В `backend/models/document.py` использовался метод `.get()` для объекта `sqlite3.Row`, который его не поддерживает.

**Решение:** Заменен `row.get()` на функцию `safe_get()`, которая проверяет наличие ключа через `row.keys()`.

**Файлы:**
- `backend/models/document.py` - исправлен метод `from_row()`
- `backend/routes/documents.py` - исправлен доступ к полям Row

### 2. Ошибка `table_name is not defined` при загрузке документов
**Проблема:** Переменная `table_name` использовалась до определения.

**Решение:** Добавлено определение `table_name` перед использованием в функции `create_document()`.

**Файл:** `backend/routes/documents.py`

### 3. Битые символы в URL (кириллица)
**Проблема:** Пути с кириллицей неправильно кодировались в URL, что приводило к ошибкам загрузки файлов.

**Решение:**
- В `backend/app.py` добавлена декодировка URL через `urllib.parse.unquote()`
- В `frontend/index.html` добавлено правильное кодирование путей через `encodeURIComponent()`

**Файлы:**
- `backend/app.py` - функция `serve_storage_file()`
- `frontend/index.html` - функция `loadFilePreview()`

## 🎯 Добавленный функционал

### 1. Предпросмотр документов
**Реализовано:**
- **PDF** - встроенный просмотр через `<iframe>`
- **DOCX/DOC** - предпросмотр через Office Online Viewer (Microsoft)
- **XLSX/XLS** - предпросмотр через Office Online Viewer
- **RTF/TXT** - загрузка и отображение текстового содержимого
- **Изображения** (JPG, PNG, GIF) - встроенный просмотр

**Файл:** `frontend/index.html` - функция `loadFilePreview()`

### 2. Поиск по содержимому с функционалом
**Реализовано:**
- Подключение к API `/api/search/content`
- Отображение результатов поиска
- Кнопки "Скачать" и "Предпросмотр" для каждого документа
- Отображение метаданных (тип, отдел, дата)

**Файл:** `frontend/index.html` - функция `performContentSearch()`

### 3. Улучшенная сортировка документов
**Реализовано:**
- Сортировка по дате (с учетом NULL значений через COALESCE)

- Сортировка на клиенте через функцию `sortDocuments()`

**Файлы:**
- `backend/routes/documents.py` - улучшен SQL запрос
- `frontend/index.html` - функция `sortDocuments()`

### 4. Правила классификации для админа
**Реализовано:**
- API для управления правилами (`/api/classification/rules`)
- Форма добавления правил
- Таблица с отображением правил
- Возможность удаления правил

**Файлы:**
- `backend/routes/classification.py` - новый модуль
- `backend/app.py` - регистрация blueprint
- `frontend/index.html` - функции `loadClassificationContent()`, `addClassificationRule()`, `deleteClassificationRule()`

## 👥 Роли пользователей

### Администратор (`admin`)
- Полный доступ ко всем документам
- Управление правилами классификации
- Просмотр статистики
- Управление пользователями (в планах)

- Доступ к документам своего отдела
- Просмотр документов, адресованных отделу
- Загрузка документов в свой отдел
- Редактирование документов отдела

### Обычный сотрудник (`user`)
- Доступ к документам своего отдела
- Доступ к личным документам (созданным им)
- Доступ к документам, адресованным ему
- Загрузка документов в свой отдел
- Редактирование документов отдела

**Файл:** `backend/services/permissions.py` - функции проверки прав

## 📋 Структура хранения документов

Документы сохраняются по структуре:
```
storage/
├── internal/           # Внутренние документы
│   └── {отдел}/
│       └── {год}/
│           └── {тип}/
│               └── {дата}/
│                   └── {срок_исполнения}/
│                       └── {файл}
└── external/          # Внешние документы
    └── (аналогично)
```

**Особенности:**
- Автоматическое создание директорий
- Санитизация имен (удаление недопустимых символов)
- Правильная обработка кириллицы в путях

## 🚀 Как использовать

### Загрузка документа
1. Выберите файл
2. Заполните обязательные поля (отдел, дата)
3. Опционально: тип документа, срок исполнения
4. Нажмите "Загрузить документ"

### Просмотр документа
1. Откройте документ из списка или дерева файлов
2. Для PDF, изображений - автоматический предпросмотр
3. Для DOCX/XLSX - предпросмотр через Office Online Viewer
4. Для других форматов - кнопка скачивания

### Поиск документов
1. Перейдите в "Поиск и документы" → "Поиск по содержимому"
2. Введите запрос
3. Нажмите "Найти"
4. Используйте кнопки "Скачать" или "Предпросмотр"

### Правила классификации (только админ)
1. Перейдите в "Классификация"
2. Заполните форму: название, условие, действие, приоритет
3. Нажмите "Добавить правило"
4. Правила применяются автоматически при загрузке
