# Система прав доступа

## Роли пользователей

### 👑 Администратор (admin)
- **Полные права** на все операции
- Может просматривать, создавать, редактировать и удалять любые документы
- Управление пользователями и отделами
- Доступ ко всем отделам и документам

### 👔 Руководитель отдела (manager)
- Может просматривать **все документы своего отдела**
- Может создавать документы в своем отделе
- Может редактировать документы своего отдела
- Не имеет доступа к документам других отделов (кроме общих/публичных)

### 👤 Обычный сотрудник (user)
- Может просматривать документы, связанные с ним:
  - Документы **своего отдела** (например, если работает в отделе закупок - все документы по закупкам)
  - Документы, **созданные лично им** (где он является автором)
  - Документы, **адресованные ему** (где он является получателем)
- Может создавать новые документы
- Может редактировать только свои собственные документы

## Примеры доступа

### Сотрудник отдела закупок (user)
Может видеть:
- ✅ Все документы отдела закупок (внутренние и внешние)
- ✅ Документы, созданные им лично
- ✅ Документы, адресованные ему
- ❌ Документы IT-отдела (если не адресованы ему)
- ❌ Документы других отделов

### Руководитель отдела закупок (manager)
Может видеть:
- ✅ Все документы отдела закупок
- ✅ Может управлять документами отдела
- ❌ Документы других отделов

### Администратор (admin)
Может видеть:
- ✅ Все документы всех отделов
- ✅ Полный доступ ко всем операциям

## Реализация в SQL запросах

### Для обычного сотрудника (user):
```sql
-- Внутренние документы отдела пользователя
SELECT * FROM internal_documents 
WHERE department_id = :user_department_id

-- Документы, созданные пользователем
OR author_id = :user_id

-- Документы, адресованные пользователю
OR recipient_user_id = :user_id
```

### Для руководителя отдела (manager):
```sql
-- Все документы отдела
SELECT * FROM internal_documents 
WHERE department_id = :user_department_id
OR recipient_department_id = :user_department_id
```

### Для администратора (admin):
```sql
-- Все документы без ограничений
SELECT * FROM internal_documents
```

## Текущие пользователи в системе

| Роль | Количество | Описание |
|------|-----------|----------|
| admin | 1 | Администратор системы |
| manager | 3 | Руководители отделов (IT, Закупки, Кадры) |
| user | 5 | Обычные сотрудники различных отделов |

## Примечания

- Система прав будет реализована на уровне веб-интерфейса
- В базе данных роли хранятся в поле `role` таблицы `users`
- Дополнительные права можно добавить через расширение структуры БД в будущем
