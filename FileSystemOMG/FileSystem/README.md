# Система управления документами компании

Система для сортировки, хранения и управления документами компании (внутренними и внешними) с возможностью просмотра, загрузки и поиска по заданным фильтрам.

## 🎯 Возможности

- ✅ Авторизация пользователей с разными ролями
- ✅ Загрузка и хранение документов (doc, docx, pdf, rtf, txt, xlsx, jpg)
- ✅ Автоматическая сортировка файлов по структуре
- ✅ Просмотр документов с фильтрацией и сортировкой
- ✅ Поиск по каталогам и содержимому
- ✅ Уведомления о полученных документах и сроках
- ✅ Статистика для администратора
- ✅ Проверка прав доступа на всех уровнях

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Инициализация базы данных
```bash
python database/init_db.py
python database/update_users_passwords.py
python database/create_notifications_table.py
python database/add_expiry_date.py
```

### 3. Запуск сервера
```bash
python run.py
```

Сервер будет доступен на `http://localhost:5000`

### 4. (Опционально) Запуск планировщика проверки сроков
```bash
python backend/tasks/scheduler.py
```
