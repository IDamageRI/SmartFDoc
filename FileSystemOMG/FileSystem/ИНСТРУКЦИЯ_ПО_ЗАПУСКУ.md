# Инструкция по запуску проекта

## Описание проекта

Система управления документами компании - веб-приложение для сортировки, хранения и управления документами (внутренними и внешними) с возможностью просмотра, загрузки и поиска по заданным фильтрам.

## Технологии

- **Backend**: Flask (Python)
- **База данных**: SQLite
- **Файловое хранилище**: Локальная файловая система
- **Авторизация**: Session-based

## Шаг 1: Установка зависимостей

```bash
cd FileSystem
pip install -r requirements.txt
```

### Требуемые пакеты:
- Flask==3.0.0
- Werkzeug==3.0.1
- schedule==1.2.0
- python-docx==1.1.0
- PyPDF2==3.0.1
- openpyxl==3.1.2
- pypandoc==1.13

## Шаг 2: Инициализация базы данных

Если база данных еще не создана, выполните:

```bash
python database/init_db.py
```

Затем выполните миграции:

```bash
# Добавление паролей пользователям
python database/update_users_passwords.py

# Создание таблицы уведомлений
python database/create_notifications_table.py

# Добавление поля expiry_date
python database/add_expiry_date.py

# Добавление пользователей (если их еще нет)
python database/add_users.py
```

## Шаг 3: Запуск сервера

```bash
python run.py
```

Сервер запустится на:
- http://localhost:5000
- http://127.0.0.1:5000
- http://[ваш_IP]:5000

API доступен по адресу: http://localhost:5000/api

## Шаг 4: (Опционально) Запуск планировщика проверки сроков

В отдельном терминале:

```bash
python backend/tasks/scheduler.py
```

Планировщик будет проверять сроки документов каждый день в 09:00 и каждые 6 часов.

## Доступ к веб-интерфейсу

Откройте в браузере: `http://localhost:5000`

## Тестирование API

### 1. Проверка доступности сервера

```bash
curl http://localhost:5000/api/health
```

### 2. Авторизация

```bash
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d "{\"username\": \"admin\", \"password\": \"123\"}"
```

### 3. Получение списка отделов

```bash
curl http://localhost:5000/api/departments \
  -H "Cookie: document_session=YOUR_SESSION_ID"
```

### 4. Просмотр документов

```bash
curl http://localhost:5000/api/documents \
  -H "Cookie: document_session=YOUR_SESSION_ID"
```

## Структура хранения файлов

После загрузки документы сохраняются в:

```
storage/
├── internal/          # Внутренние документы
│   └── {отдел}/
│       └── {год}/
│           └── {тип документа}/
│               └── {дата}/
│                   └── {срок исполнения}/
│                       └── {файл}
└── external/          # Внешние документы
    └── (аналогичная структура)
```

## Возможные проблемы

1. **Ошибка импорта модулей**: Убедитесь, что все зависимости установлены
2. **Ошибка БД**: Проверьте, что выполнены все миграции
3. **Порт занят**: Измените порт в `run.py` (по умолчанию 5000)
4. **Проблемы с кодировкой**: Убедитесь, что терминал поддерживает UTF-8
